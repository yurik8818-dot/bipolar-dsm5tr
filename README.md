# Диагностика биполярного спектра (DSM-5-TR)

Пошаговый клинический алгоритм для специалиста: дифференциальная диагностика расстройств биполярного спектра по критериям DSM-5-TR. Коды ICD-10-CM и МКБ-11 указаны справочно.

## Что умеет

- 6 этапов: этиологический фильтр, полюс подъёма, депрессивный полюс, циклотимия, спецификаторы, дифференциальный диагноз
- живые шкалы критериев с отметкой порога (критерий B мании/гипомании, критерий A БДЭ)
- рабочая гипотеза с кодом ICD-10-CM (F31.x, F32.x, F33.x, F34.0) и МКБ-11
- диаграмма полюсов, спецификаторы, проверка противоречий в ответах
- отдельный блок безопасности при суицидальном риске
- копирование заключения в буфер для медкарты
- черновик ответов в браузере (ID пациента не сохраняется)
- светлая и тёмная тема, адаптивная вёрстка для телефона

## Как запустить

Один файл без сборки и зависимостей: откройте `index.html` в браузере.

Чтобы получить ссылку на сайт, включите GitHub Pages: **Settings → Pages → Source: Deploy from a branch → main / (root)**.

## Важно

Инструмент вспомогательный и не заменяет клиническое интервью. Результат является рабочей гипотезой по введённым ответам; диагноз ставит врач-психиатр.

Коды ICD-10-CM сверены с таблицей соответствия DSM-5 / ICD-10-CM. Подкоды МКБ-11 не детализированы.
